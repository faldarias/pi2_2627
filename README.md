## Descripción

Este repositorio reúne los materiales y recursos del módulo Proyecto
Intermodular II de segundo curso del ciclo formativo de Administración de
Sistemas Informáticos en Red (ASIR). Incluye guías, contenidos de las unidades,
documentos en distintos formatos y recursos complementarios.

Para navegar por el material, abre el [índice principal](index.html). Cada
página de unidad incluye un enlace para volver a la portada.
