1. ¿Qué es Packet Tracer?

Cisco Packet Tracer es un simulador de redes. Para poder compartir y abrir correctamente los archivos de prácticas, es importante utilizar la misma versión: la versión 8.2.1 no abre los archivos creados con la versión 8.2.2.

2. Descarga

Cisco Packet Tracer 8.2.2 se puede descargar gratuitamente desde Cisco Networking Academy. Inicia sesión en NetAcad y accede a NetAcad Legacy > Resources > Packet Tracer.

Página de descarga de Packet Tracer

3. Instalación en Ubuntu

Estas instrucciones corresponden a Ubuntu 24.04.2 LTS.

  1. Descarga el instalador Packet_Tracer822_amd64_signed.deb desde la página de Packet Tracer .
  2. Descarga la biblioteca libgl1-mesa-glx_23.0.4-0ubuntu1.22.04.1_amd64.deb. Consulta la referencia sobre la biblioteca .
  3. Instala la biblioteca desde la terminal: 
    sudo dpkg -i libgl1-mesa-glx_23.0.4-0ubuntu1.22.04.1_amd64.deb
  4. Instala Packet Tracer: 
    sudo dpkg -i Packet_Tracer822_amd64_signed.deb
  5. Si quedan dependencias pendientes, ejecuta: 
    sudo apt --fix-broken install

4. Acceso a las líneas de comandos

  • PC: abre PC > Desktop > Command Prompt > Run.
  • Router: abre Router > CLI.

5. Problemas de validación al abrir archivos

Al abrir un archivo de Packet Tracer, puede aparecer una solicitud de validación. En algunos casos, aunque el inicio de sesión parezca completarse, la aplicación sigue solicitándolo cada vez que se vuelve a abrir el archivo.

La solución indicada es iniciar sesión desde la nueva plataforma de NetAcad, en lugar de hacerlo desde NetAcad Legacy.
